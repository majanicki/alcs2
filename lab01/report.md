We consider the Quadratic Assignment Problem, a classical combinatorial optimization problem in which a set of facilities must be assigned to a set of locations in a way that minimizes the total cost. The cost is defined based on flows between facilities and distances between locations, leading to a quadratic objective function.

The instances were chosen to ensure diversity in size and the structure, in order to increase difficulty for the algorithm. ### Our Implementation

The implementation was written in Go and focuses on efficiency and fair comparison of different algorithms for the Quadratic Assignment Problem. Solutions are represented as permutations, and the objective function is evaluated using a standard quadratic cost formulation based on flow and distance matrices stored in row-major format.

To improve performance, a delta evaluation function is implemented, allowing the cost difference between neighboring solutions (generated by swapping two positions) to be computed in 𝑂(𝑛) time instead of recomputing the full objective in 𝑂(𝑛^2). This is crucial for local search methods (Greedy and Steepest), which evaluate many neighboring solutions.


### Neighbour Operator

The implemented algorithms use a 2-swap neighborhood operator, which is standard for the Quadratic Assignment Problem. A neighboring solution is generated by selecting two distinct positions i and j in the permutation and swapping the assigned facilities. The size of the neighborhood for a permutation of size n is: n(n-1)/2. Instead of recomputing the full objective function for each neighbor (which would take 0(n^2)) the implementation uses a delta evaluation function that computes the cost difference between two solutions differing by a swap in 0(n) in time.

#### Quality

The quality of a solution is defined as: 
`quality = (f(π) - f*) / f* * 100` 
where:
 - f(π) is the objective value of the obtained solution,
 - f* is the optimal (or best-known) objective value.

This measure represents the relative percentage deviation from the optimum.

#### Efficiency

Efficiency is defined as:
`efficiency = quality / (time + ε) * 100`
where:

 - quality is the relative error defined above,
 - time is the runtime of the algorithm,
 - ε is a small constant to avoid division by zero.

This measure captures the trade-off between solution quality and computational time, as it rewards algorithms that achieve low error quickly, while penalizing those that are either slow or produce poor-quality solutions; additionally, it enables meaningful comparison between fundamentally different approaches (e.g., fast random methods versus slower local search methods) when solving instances of the Quadratic Assignment Problem.

### Conclusions

The QAP is a highly multimodal and combinatorially complex problem, with many local optima and a search space that grows factorially with problem size. As a result, no single algorithm guarantees optimal solutions for larger instances, and performance strongly depends on both exploration and exploitation strategies. Multi-start approaches and randomization are essential to reliably discover high-quality solutions.

According to the oobservations, there is no significant correlation between the quality of initial solutions and the final local optima, highlighting the ruggedness of the search space.Efficiency, measured as solution quality per unit time, favors local search methods over pure random approaches, especially for larger instances.

Smaller, structured instances (e.g., esc16, esc32f) can be solved close to optimum in almost every run, while larger and irregular instances (e.g., tai256c, sko100a) show significant variability in local optima quality.
Randomized and multi-start methods are crucial for larger instances, where single-run local search often gets trapped in suboptimal regions.

In summary, the project confirms that for QAP, multi-start local search with randomized neighborhood exploration is a reliable and efficient approach, while pure random methods are useful primarily for broad exploration or benchmarking. The structure of the search space limits the influence of initial solutions, emphasizing the importance of repeated and diversified searches to achieve high-quality results.

### Suggestions for future improvements and their expected effects

Suggested improvements:
 - Applying Hybrid Metaheuristics, which Combines local search with adaptive metaheuristics such as Tabu Search, Simulated Annealing, or Genetic Algorithms could improve exploration, helping avoid local optima traps and potentially discovering better solutions.
 - Running multiple local searches or neighborhood evaluations in parallel could drastically reduce runtime, especially on large instances like tai256c.

Overall, the implemented and proposed improvements target both algorithmic efficiency and solution effectiveness, providing a strong foundation for further enhancements in solving large and complex QAP instances.
